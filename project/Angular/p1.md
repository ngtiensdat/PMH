# PHẦN 1. Nền tảng Web (HTML, CSS, JavaScript, TypeScript)

Chào mừng bạn đến với bài học đầu tiên! Để làm việc hiệu quả với Angular, bạn cần có nền tảng vững chắc về 4 cột trụ của lập trình Web hiện đại: **HTML**, **CSS**, **JavaScript** và **TypeScript**. Dưới đây là nội dung chi tiết của từng phần cùng các ví dụ thực tế.

---

## 1. HTML (HyperText Markup Language)
HTML đóng vai trò làm **khung xương** (cấu trúc) cho trang web. Mọi thành phần hiển thị trên màn hình đều được định nghĩa bằng các thẻ (tags) HTML.

### Các thẻ cơ bản thường gặp trong Angular
*   `<div>` (Division): Thẻ khối dùng để gom nhóm các thành phần giao diện, chia bố cục.
*   `<span>`: Thẻ nội dòng (inline) dùng để định dạng văn bản nhỏ hoặc cụm từ.
*   `<p>` (Paragraph): Thẻ đoạn văn bản.
*   `<button>`: Nút bấm để kích hoạt sự kiện (như click chuột).
*   `<input>`: Ô nhập liệu cho phép người dùng nhập văn bản, số, ngày tháng...
*   `<ul>`, `<li>` (Unordered List): Tạo danh sách không thứ tự (kết hợp với `*ngFor` của Angular).

### Thẻ ngữ nghĩa (Semantic HTML)
Thay vì sử dụng lạm dụng thẻ `<div>`, HTML5 khuyến khích sử dụng các thẻ có ý nghĩa rõ ràng giúp SEO và cấu trúc trang sạch hơn:
*   `<header>`: Phần đầu trang.
*   `<nav>`: Menu điều hướng.
*   `<main>`: Nội dung chính duy nhất của trang.
*   `<section>`: Một phần/phân đoạn nội dung riêng biệt.
*   `<article>`: Một bài viết độc lập.
*   `<footer>`: Phần chân trang.

## 2. CSS (Cascading Style Sheets)
CSS đóng vai trò **trang trí và sắp xếp bố cục** (style) cho các thẻ HTML. 

### Core Concepts (Khái niệm cốt lõi)
1.  **Selectors (Bộ chọn):** Cách CSS tìm đến thẻ HTML để tô màu.
    ```css
    /* Chọn trực tiếp thẻ html */
    button { background-color: blue; }
    
    /* Chọn qua Class (Bắt đầu bằng dấu chấm) */
    .btn-primary { color: white; }
    
    /* Chọn qua ID (Bắt đầu bằng dấu # - dùng cho phần tử duy nhất) */
    #main-header { font-size: 24px; }
    ```
2.  **Box Model (Mô hình hộp):** Mọi phần tử HTML đều là một hộp chữ nhật bao gồm:
    *   `Content`: Nội dung hiển thị bên trong.
    *   `Padding`: Khoảng cách từ nội dung đến viền hộp.
    *   `Border`: Viền của hộp.
    *   `Margin`: Khoảng cách từ viền hộp ra bên ngoài (khoảng cách giữa các hộp).

3.  **Flexbox (Bố cục linh hoạt):** Công cụ chia dòng và căn chỉnh phần tử cực mạnh, được dùng nhiều nhất để dựng UI:
    ```css
    .container {
      display: flex;
      justify-content: space-between; /* Căn đều các cột */
      align-items: center;            /* Căn giữa theo chiều dọc */
      flex-direction: row;            /* Sắp xếp theo hàng ngang (hoặc column) */
    }
    ```

## 3. JavaScript (ES6+)
JavaScript giúp trang web có **hành vi động và xử lý logic**. Trong Angular, mặc dù viết bằng TypeScript nhưng khi chạy trình duyệt sẽ biên dịch ngược về JavaScript. Bạn cần nắm chắc các cú pháp JavaScript hiện đại (ES6+):

### Khai báo biến (`const` & `let`)
*   `const`: Khai báo hằng số (không thể gán lại giá trị mới).
*   `let`: Khai báo biến có thể gán lại giá trị, phạm vi hoạt động trong khối `{}` (block scope).
*   *(Tránh dùng `var` vì dễ gây lỗi rò rỉ biến ngoài phạm vi).*

### Arrow Functions (Hàm mũi tên)
Cú pháp viết hàm ngắn gọn hơn và giữ nguyên ngữ cảnh của con trỏ `this`:
```javascript
// Hàm truyền thống
function add(a, b) {
  return a + b;
}

// Arrow function
const add = (a, b) => a + b;
```

### Destructuring (Phá vỡ cấu trúc) và Spread Operator (`...`)
Giúp trích xuất dữ liệu từ Object hoặc Array nhanh chóng:
```javascript
const user = { name: 'Nguyen Van A', age: 25, role: 'Maker' };

// Destructuring
const { name, role } = user; // name = 'Nguyen Van A', role = 'Maker'

// Spread Operator (Sao chép và kế thừa Object)
const updatedUser = { ...user, age: 26 }; // age được cập nhật thành 26, các trường khác giữ nguyên
```

### Xử lý bất đồng bộ (Promises & Async/Await)
Rất quan trọng khi gọi API từ backend:
```javascript
// Dùng Async/Await giúp code bất đồng bộ trông giống tuần tự
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error("Lỗi:", error);
  }
}
```

### Các phương thức duyệt mảng phổ biến (`map`, `filter`, `reduce`)
```javascript
const numbers = [1, 2, 3, 4];

// map(): Biến đổi mảng cũ thành mảng mới cùng kích thước
const doubled = numbers.map(n => n * 2); // [2, 4, 6, 8]

// filter(): Lọc các phần tử thỏa mãn điều kiện
const evens = numbers.filter(n => n % 2 === 0); // [2, 4]
```

## 4. TypeScript (Siêu ngôn ngữ của JavaScript)
TypeScript là JavaScript được bổ sung **kiểu dữ liệu tĩnh (Static Typing)** và các tính năng hướng đối tượng mạnh mẽ. Mọi lỗi sai kiểu dữ liệu sẽ được trình biên dịch báo ngay lập tức thay vì đợi đến lúc chạy chương trình.

### Kiểu dữ liệu cơ bản (Basic Types)
```typescript
let username: string = 'admin';
let age: number = 30;
let isActive: boolean = true;
let roles: string[] = ['Maker', 'Checker']; // Mảng chứa chuỗi
let anyValue: any = 'Có thể chứa bất kỳ kiểu dữ liệu gì'; // Hạn chế lạm dụng
```

### Interface và Type (Định nghĩa cấu trúc dữ liệu)
Được dùng để đặc tả các đối tượng dữ liệu như DTO từ API trả về:
```typescript
interface UserDto {
  id: number;
  username: string;
  email: string;
  status?: number; // Dấu "?" nghĩa là trường này không bắt buộc
}

const user: UserDto = {
  id: 1,
  username: 'datga',
  email: 'datga@example.com'
};
```

### Lập trình hướng đối tượng (Class & Access Modifiers)
TypeScript hỗ trợ đầy đủ các tính năng OOP như Java hoặc C#:
```typescript
class Product {
  private id: number;      // Chỉ truy cập được bên trong Class này
  public name: string;     // Truy cập được từ bên ngoài
  protected price: number; // Chỉ truy cập được ở Class này và Class con kế thừa

  constructor(id: number, name: string, price: number) {
    this.id = id;
    this.name = name;
    this.price = price;
  }

  public getDetails(): string {
    return `Sản phẩm: ${this.name} - Giá: ${this.price} VND`;
  }
}
```

### Decorators (Trình trang trí)
Các ký hiệu bắt đầu bằng dấu `@` dùng để khai báo siêu dữ liệu (metadata) cho Class. Đây là linh hồn của Angular:
```typescript
// Báo cho Angular biết Class này là một Component
@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent {
  title = 'Dự án Payment Hub';
}
```
