# PHẦN 5. AOP (Aspect-Oriented Programming) & Dynamic Proxy

AOP giúp tách các logic phụ (như Logging, Transaction, Security) ra khỏi logic nghiệp vụ chính của bạn.

---

## 1. Dynamic Proxy hoạt động thế nào?
Khi bạn đánh dấu một hàm bằng `@Transactional`, Spring Boot sẽ không gọi trực tiếp hàm của bạn. Nó sử dụng cơ chế **Dynamic Proxy** để tạo ra một Class giả (Proxy Class) bọc ngoài class của bạn lúc chạy chương trình.

```
[Request của Client] 
     │
     ▼
┌─────────────────────────────────┐
│     Spring Proxy Class          │
│  - Mở Transaction (Connection)  │  <-- Tự động chạy
│  - Gọi Service thực tế của bạn  │
│  - Nếu thành công: Commit       │  <-- Tự động chạy
│  - Nếu lỗi: Rollback            │  <-- Tự động chạy
└─────────────────────────────────┘
```

---

## 2. Ví dụ AOP trong dự án
*   **`@Transactional`**: Tự động quản lý đóng/mở kết nối database.
*   **`@ExceptionHandler`**: Tự động bắt tất cả các Exception ném ra từ Controller để biến đổi thành định dạng thông báo lỗi JSON gửi về FE (file `GlobalExceptionHandler.java`).
