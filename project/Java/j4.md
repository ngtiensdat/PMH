# PHẦN 4. Spring Boot Core (IoC, Dependency Injection, Beans)

Spring Boot là framework đứng sau giúp quản lý vòng đời đối tượng và tự động kết nối các thành phần với nhau.

---

## 1. IoC (Inversion of Control - Đảo ngược điều khiển)
Trong Java truyền thống, nếu lớp A cần dùng lớp B, bạn phải tự viết: `B b = new B();`.
Với Spring Boot, quyền kiểm soát được trao cho **Spring Container**. Spring Container tự khởi tạo các đối tượng và tiêm vào nơi cần thiết.

---

## 2. Bean là gì?
Bean là một đối tượng được quản lý và kiểm soát vòng đời bởi Spring Container (chứ không phải đối tượng tạo bằng lệnh `new` thông thường của Java).
*   **Cách tạo Bean:** Gắn các chú thích lên class như `@Component`, `@Service`, `@Repository`, `@RestController`. Spring sẽ tự quét (Component Scan) và khởi tạo chúng thành Bean.

---

## 3. Dependency Injection (DI - Tiêm phụ thuộc)
Là hành động Spring tự động truyền (tiêm) đối tượng phụ thuộc vào class của bạn.
*   **Ví dụ trong dự án:**
    ```java
    @Service
    public class GroupCategoryServiceImpl implements GroupCategoryService {
        private final GroupCategoryRepository repository;

        // DI thông qua Constructor (Spring tự truyền repository vào)
        public GroupCategoryServiceImpl(GroupCategoryRepository repository) {
            this.repository = repository;
        }
    }
    ```
