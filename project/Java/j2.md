# PHẦN 2. Java Collections Deep Dive (HashMap, ArrayList, LinkedList)

Hệ thống Collection trong Java quản lý các nhóm đối tượng (mảng động, danh sách liên kết, cặp key-value) được sử dụng ở mọi ngóc ngách của dự án.

---

## 1. ArrayList vs LinkedList
Cả hai đều cài đặt (implement) interface `List` nhưng cấu trúc vật lý bên dưới khác nhau:

| Tiêu chí | ArrayList | LinkedList |
| :--- | :--- | :--- |
| **Cấu trúc dưới** | Mảng động (Array) | Danh sách liên kết đôi (Node) |
| **Tìm kiếm theo chỉ mục** | Siêu nhanh: $O(1)$ | Chậm: $O(N)$ (phải duyệt từ đầu) |
| **Thêm/Xóa phần tử** | Chậm (do phải dịch chuyển mảng) | Nhanh: $O(1)$ (chỉ cập nhật con trỏ) |

*   **Ứng dụng:** Trong dự án, `ArrayList` được dùng nhiều nhất (`new ArrayList<>()`) vì chúng ta thường xuyên duyệt qua dữ liệu và tìm kiếm theo chỉ mục để hiển thị.

## 2. HashMap hoạt động bên dưới thế nào?
`HashMap` lưu trữ dữ liệu dạng cặp `Key - Value`.
*   **Cơ chế Hash (Băm):** Khi bạn gọi `map.put(key, value)`, Java lấy mã băm (`hashCode()`) của `key` để tính toán ra vị trí (bucket) lưu trữ trong mảng vật lý bên dưới.
*   **Xử lý đụng độ (Collision):** Nếu hai key khác nhau có cùng mã băm và trỏ vào một vị trí:
    *   *Java 7 trở về trước:* Dùng LinkedList để nối tiếp các phần tử đụng độ. Truy cập sẽ chậm đi thành $O(N)$.
    *   *Java 8 trở đi:* Nếu số lượng phần tử đụng độ trong 1 bucket vượt quá 8, Java tự động chuyển LinkedList đó thành **Cây đỏ-đen (Red-Black Tree)**, giúp tăng tốc độ tìm kiếm từ $O(N)$ lên $O(\log N)$.
