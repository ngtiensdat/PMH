# PHẦN 7. REST APIs, Validation & Exception Handling

REST API là phương thức giao tiếp chuẩn giữa Frontend (Angular) và Backend (Spring Boot).

---

## 1. Cấu trúc REST API chuẩn
*   **GET `/api/components`**: Lấy danh sách.
*   **GET `/api/components/{code}`**: Lấy chi tiết.
*   **POST `/api/components`**: Thêm mới.
*   **PUT `/api/components/{code}`**: Cập nhật.
*   **DELETE `/api/components/{code}`**: Xóa.

---

## 2. Kiểm lỗi dữ liệu (Validation)
Sử dụng gói `jakarta.validation.constraints` để ràng buộc dữ liệu tại lớp DTO:
*   `@NotBlank`: Chuỗi không được để trống.
*   `@Size(min=x, max=y)`: Độ dài giới hạn.
*   `@Pattern(regexp=...)`: Kiểm tra định dạng (Regex).

---

## 3. Exception Handling (Xử lý lỗi tập trung)
Sử dụng `@RestControllerAdvice` để biến các lỗi khô khan của hệ thống thành JSON sạch đẹp trả về cho FE:
```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ApiResponse<Map<String, String>>> handleValidation(MethodArgumentNotValidException ex) {
        // Thu thập toàn bộ lỗi validate đầu vào để gửi về FE hiển thị
    }
}
```
